# 坦克大战第二版

用 Java + AWT 从零写的坦克大战学习项目。当前停在「地图块类型 + 老巢 + 坦克撞块 + 开火冷却」这一阶段。

> 文档按 `src` 当前实际代码逐行核对，对齐提交 `fdca795`（2026-11-23）。
> 详细内容按主题拆到 `docs/`，本篇只做总览和导航。

## 当前进度

```text
窗口 → 菜单 → 状态机 → 双缓冲 → 坦克移动
     → 开火 → 子弹对象池 → 抽象 Tank 类 → 玩家/敌人拆分
     → 敌人生成与 AI → 子弹↔坦克 → 爆炸 → 扣血/血条/名字
     → 地图层 → 地图块对象池 → 子弹↔块按类型扣血
     → 老巢 TankHouse → 坦克↔块阻挡 → 开火冷却 125ms
                                      ▲ 你在这
下一步：手工关卡、钢/水/草生成、水草通行规则、老巢防重叠
```

## 运行方式

用 IntelliJ IDEA 打开项目根目录，运行 `com.pawamamama.app.GameMain`。

注意：`res/` 是相对工作目录的路径，运行时工作目录必须是项目根目录。

## 项目结构

```text
newTank/
├── res/         图片素材（坦克、爆炸、地图块、结束图）
├── tools/       Python 素材生成脚本（运行不依赖）
├── src/         Java 源码
│   └── com/pawamamama/
│       ├── app/     入口
│       ├── game/    窗口、渲染、子弹、爆炸
│       ├── Tank/    坦克模型
│       ├── map/     地图、地图块、老巢
│       └── util/    常量、工具、四个对象池
└── docs/        本系列文档
```

## 核心数据

| 项 | 值 |
|---|---|
| 逻辑画布 | 900 × 700，显示放大 1.5 倍 |
| 刷新间隔 | 30 ms |
| 地图 | 19 × 14 格，每格 40 × 40 |
| 地图块 | `BRICK` / `STEEL`(3 血) / `WATER` / `GRASS` / `HOUSE` |
| 坦克 | 半径 20，血量 1000，攻击 100 |
| 开火 | 每秒最多 8 发（125ms 冷却） |
| 敌人 | 同屏最多 10 辆，每 5 秒生成一辆 |
| 对象池 | 子弹 200/300、爆炸 10/30、敌人 10/15、地图块 200/400 |
